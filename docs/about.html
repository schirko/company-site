About Cornerpost Logic

Cornerpost Logic builds decision tools for ranchers and farmers, based in Centennial, Colorado.

Most farm software keeps records. Ours starts where the records stop: turning a rancher's own herd book, a farmer's fields and public data from USDA and NASA into an answer to a real question. Which calves should I sell this fall? What will this county's corn yield? Is a bigger combine worth it?

Each app is built the same way. We start with the decision, find the data that bears on it, test the model on years and places it hasn't seen, and show the answer with a range and the reasons behind it. When a method doesn't hold up, we say so. How We Test shows the results for each app.

The apps

  • Herd Planner: Keep-or-sell decisions for cow-calf ranches.
  • Yield Predictor: County crop yields from weather, soils and irrigation.
  • Farm Equipment Planner: Whether a tractor, combine or implement pays for itself (coming soon).
